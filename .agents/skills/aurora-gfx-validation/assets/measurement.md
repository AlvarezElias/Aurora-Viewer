# Experiment record

Status: planned; no result is claimed until the observations below are filled.

## Question and scope

Task ID, hypothesis, baseline/candidate and intended acceptance criterion.

## Configuration

Commit, date, exact GPU/memory, OS/toolchain, power mode, dependency/model
version, demo scenario/camera, launch-only options and effective settings
observed in the log. Never include credentials or personal paths.

## Method

Commands, internal/output resolutions, warmup, sampling interval, sample count,
run order, GPU load and latency-measurement method if one is available.

## Observations

Record measured GPU time, frame-time variation, memory, real rendered and
presented FPS separately. Write unavailable for unmeasured quantities. Add
sanitized evidence references and actual visual findings, including regressions.

## Result and limitations

State whether the hypothesis was supported, rejected or remains inconclusive.
Do not use a documentation check or third-party benchmark as a local result.

## Human acceptance

Pending. After testing, record who accepted in a non-personal role description,
the date and the exact behaviour/configuration accepted. A grid test is done
by the human, never by the agent.

## Next step

The next experiment, correction, stop decision or authorized integration.
